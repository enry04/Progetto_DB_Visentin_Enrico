# Progetto_DB_Visentin_Enrico

Si vuole realizzare una base di dati dedicata alla gestione di tornei calcistici. L'obiettivo principale della piattaforma è di supportare e monitorare le varie competizioni, consentendo la gestione delle squadre, partite, atleti, stadi e statistiche di gioco.\\
Il sistema dovrà supportare la registrazione di società sportive, squadre, singoli atleti, partite e impianti sportivi.\\
Dovrà inoltre permettere la consultazione dei risultati, delle classifiche e delle prestazioni individuali dei giocatori durante le varie stagioni sportive.
